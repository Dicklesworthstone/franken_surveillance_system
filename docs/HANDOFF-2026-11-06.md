## LESSONS LEARNED (read before debugging)
1. **Five defects mask each other** — fix one, test, fix the next. Any single
   fix alone produces "nothing happens" with no error.
2. **The dl-loc loop** — the camera asks with its OWN version; answering with
   that same version is self-referential. Always answer with the ADVERTISED version.
3. **lsof hangs on autofs** — 22 s per call. Use netstat -anv instead.
4. **netstat under #!/bin/bash** — one session env var makes it output nothing.
   Shell out to /bin/sh -c for the netstat call.
5. **sudo scrubs the env** — NO_UPSTREAM=1 from launchd never reached the exec'd
   proxy. Pass it explicitly: `sudo env NO_UPSTREAM=1 …`
6. **exec doesn't fire the EXIT trap** — remove the lock file before exec or
   new generations defer to the running proxy forever.
7. **Atomic cert writes** — the concurrent MQTT proxy crashes with "PEM lib"
   on partial reads. tmp+rename.
8. **The dl-loc version loop** — always serve the ADVERTISED version, never the
   camera's installed version.
9. **The entrypoint beacon** — use wget (the camera's busybox may lack curl).
10. **Increment the shadow delta version** — a fixed offset is stale after the
    first processing.
11. **Adopt, don't kill, the running proxy** — killing it drops the camera's
    MQTT session and triggers a 2+ hour backoff.
12. **pf rdr for dead endpoints** — the camera's pinned IP:port may stop
    answering; redirect to the MITM.
